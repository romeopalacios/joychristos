# Joy Christos Portfolio

Modern, responsive artist portfolio for Joy Christos — singer and actress.

## Project structure

- `index.html`
- `styles.css`
- `script.js`
- `media/joy-headshot.jpeg`
- `media/joy-bts.jpeg`

## Open in VS Code

1. Extract the ZIP.
2. Open the `joy-christos-portfolio` folder in VS Code.
3. Right-click `index.html`.
4. Select **Open with Live Server**.

## Customize

Replace placeholder social links, booking email, bio text, reel links, and form behavior.

The contact form is a front-end demo until connected to Formspree, HubSpot, Airtable, or a backend.
